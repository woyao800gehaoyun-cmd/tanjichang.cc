手机端用 **Shadowrocket（小火箭）**、圈 X（Quantumult X）或 Stash，电脑端用 **v2rayN / v2rayNG** 的朋友，选机场其实不用看太复杂，记住“订阅一键导入 + 延迟低”就够了。

## iOS 小火箭订阅推荐

小火箭对 Trojan 和 Shadowsocks 协议兼容最稳，耗电也低：
- **光年梯（光年梯VPN / 专线）**：扫码或一键导入小火箭，默认分流就很好用，出门切 5G 流量重连速度很快。
- **极连云**：节点列表干净，刷 X、Instagram 和 YouTube 1080P/4K 都很流畅。

## Windows v2rayN / 安卓 v2rayNG 推荐

v2rayN 胜在轻巧不占内存，适合办公电脑长期挂后台：
- **光年梯 / 速界**：适合跨境办公、拉取 GitHub 代码和远程会议，丢包率低。
- **边缘节点**：支持 VLESS Reality，适合喜欢在 v2rayN / sing-box / Hiddify 里折腾冷门地区节点的老玩家。
